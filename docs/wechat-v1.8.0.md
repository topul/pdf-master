# 一天更新 11 个功能：PDF Master 超级大版本来了

今天这一版，我们自己都觉得有点离谱。

从早上到下午，PDF Master 一次性上了 **11 个新功能**。版本号直接跳到 **v1.8.0**。

下面一个一个说。

---

## 01｜PDF 转 Word

呼声最高的功能之一。

选中 PDF，点转换，得到一份 `.docx` 文件。排版、文字、表格基本保留，直接拿 Word 接着编辑就行。

不用开浏览器，不用上传到任何网站，全程本地完成。

## 02｜PDF 转 Excel

能自动识别 PDF 里的表格结构，提取出来变成 `.xlsx`，列对齐、数据完整。

财务同学狂喜。

## 03｜PDF 批注：高亮、便签、注释

以前 PDF Master 偏"处理"，不太适合阅读。这次加了批注功能：

- 文字高亮（多颜色）
- 便签注释
- 自由标注

批注完直接保存回 PDF，下次打开还在。

## 04｜表单创建

在 PDF 上加 AcroForm 字段——文本框、复选框、单选框、下拉框。

做完分发给同事填写，回收后还能用"填写表单"功能继续处理。

## 05｜PDF 对比

两份 PDF 放一起，自动高亮差异。

改合同、对版本的时候特别有用，不用再肉眼一行行扫了。

## 06｜OCR 识别

扫描件、图片型 PDF，现在能识别成可编辑文字了。

- 支持多语言（中文、英文、混合）
- 基于 Tesseract.js，完全本地运行

## 07｜去除水印

不需要的文字水印，选中后一键移除。

## 08｜历史记录：打开就能接着干

首页现在会自动记住最近打开的 20 个文件：

- 跨会话持久保存，关软件不丢
- 显示文件大小和相对时间（"5 分钟前"）
- 点击一键打开
- 支持单条删除和一键清空

用过就回不去了。

## 09｜右键菜单

文件列表支持右键了，弹出"打开"和"删除"。

- Esc 键关闭
- 点击外部关闭
- 自动避开屏幕边缘

后续会铺到更多场景。

## 10｜批量重命名：50 份文件一秒改名

选多个 PDF，设命名规则，一键改名。

**支持的变量：**

```
{index}   → 1, 2, 3...
{Index}   → 01, 02, 03...
{INDEX}   → 001, 002, 003...
{name}    → 保留原文件名
```

**举个例子：** 50 份合同想统一命名，填规则 `合同_{INDEX}_2026.pdf`，预览没问题，点保存。完事。

有重名会标黄提醒，不会瞎改。

## 11｜全局快捷键

新增了快捷键支持：

- `Ctrl/Cmd + O` 打开文件
- `Ctrl/Cmd + N` 新建窗口
- `Ctrl/Cmd + Home` 返回首页
- `Ctrl/Cmd + 1~9` 快速跳转功能页

熟练之后效率翻倍。
