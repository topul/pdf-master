# 我把 PDF Master 更新到了 v1.8.0，这次塞了 11 个新功能

先说结论：今天这版，是我写过最"疯狂"的一次更新。

不是计划好的。原本只想加两三个功能，结果做着做着收不住，最后数了一下——11 个新功能。

下面不按编号流水账式地列了，挑几个重点聊聊。

---

## 先说最炸的：PDF 转 Word 和 Excel

这俩是后台被问得最多的。

以前我一直没做，因为坑多——排版丢失、表格错位、乱码……哪个都够喝一壶。

这次终于搞定了。

**转 Word**：排版、文字、表格基本保留，拿到 `.docx` 直接接着编辑。
**转 Excel**：自动识别表格结构，输出 `.xlsx`，列对齐、数据完整。

最关键的是——**全程本地**。不用上传到任何网站，不用担心文件泄露。

你想想，一份合同里有敏感条款，你敢传到在线转换网站吗？

## 再说一个被催了八百遍的：OCR

扫描件、图片型 PDF，以前在 PDF Master 里就是张图，选不了文字。

现在能识别了。中文、英文、混排都行，基于 Tesseract.js，跑在你自己电脑上。

装过 OCR 库的都知道，这玩意儿配置起来有多烦。这次直接内置，点一下就能用。

## 一个"小"功能，但用了就回不去：历史记录

这个我本来没当回事，结果自己用了一下午就真香了。

打开软件，首页直接显示你最近打开过的 20 个 PDF。显示文件大小、打开时间，点一下就接着干。

不用每次都去翻文件夹。尤其每天处理大量文件的人，省下来的时间积少成多。

配合右键菜单——文件上右键，直接"打开"或"删除"，不用找按钮。

## 批量重命名：解决一个真实痛点

后台有人留言：200 份合同，文件名乱七八糟，怎么批量改名？

以前我只能说：写个 Python 脚本。现在不用了。

选多个 PDF，设个规则，一键搞定：

```
{index}   → 1, 2, 3...
{Index}   → 01, 02, 03...
{INDEX}   → 001, 002, 003...
{name}    → 保留原文件名
```

输入 `合同_{INDEX}_2026.pdf`，预览确认，点保存。50 份文件一秒改名。

有重名会标黄提醒，不会瞎改。

## 其他几个，简单带过

- **PDF 批注**：高亮、便签、注释，保存回 PDF
- **表单创建**：在 PDF 上加文本框、复选框等字段
- **PDF 对比**：两份 PDF 放一起，高亮差异
- **去除水印**：一键移除文字水印
- **全局快捷键**：Ctrl+O 打开、Ctrl+1~9 跳转功能页

每一个单独拎出来都能写一篇，但今天篇幅有限，就不展开了。

## 关于 PDF Master

简单说：**一个完全在本地跑的 PDF 工具集。**

不联网、不上传、不经过任何第三方服务器。文件从打开到处理再到保存，全程在你自己硬盘上完成。

合并、拆分、编辑、压缩、加密、水印、转换、OCR……算上这次更新，已经有 30 多项功能。

Windows、macOS、Linux 都能用。

**项目地址：** github.com/topul/pdf-master

觉得有用，Star 一下就是对项目最大的支持。
